Mixtormat / Agent implementation reference

Generator relationships — HTML/CSS UX concepts

Four proposed behaviors using the existing compact dark editor language. These are interaction mockups, not evidence of implemented features.

Text-only interface, no iconography. Native checkboxes and text labels are deliberate. Measurements are proposed, not measurements of the shipped UI.

Tradeoff: Clearest display of source/operation/target, but many connections increase stack height. Preferred as the persistent relationship language.
